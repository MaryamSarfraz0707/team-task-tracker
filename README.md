
# Team Task Tracker

A small full-stack application for creating, viewing, filtering,
updating, and deleting tasks.

## Technology Stack
- Frontend: Angular + TypeScript
- Backend: C# + ASP.NET Core Web API
- Data access: Entity Framework Core
- Database: SQL Server Express (subject to manager approval)

## Project Structure
- database/ — SQL schema, seed data, verification queries
- api/ — ASP.NET Core Web API
- client/ — Angular application
- docs/ — Proposal and technical documentation

## Git Branches
- master — reviewed integration branch
- database — database development
- backend — API development
- frontend — Angular development

## Workflow
Feature branches merge into their respective layer branches.
Reviewed layer branches merge into master through pull requests.
